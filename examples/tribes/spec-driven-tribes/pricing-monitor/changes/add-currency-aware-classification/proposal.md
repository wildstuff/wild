# Change: Add currency-aware classification

Risk: high

## Intent

The classifier today reads only `delta_pct`. When competitor B
flips its display currency on Mondays during sales (EUR → USD),
we get a -50% reading that is not a real flash-sale. The
classifier mis-labels it; alerts go out; Sarah loses trust.

The brief at `briefs/price-change-detection.md` already
documents this failure mode under "Currency switch on the
page". The chief's reasoning today won't catch it because the
spec doesn't tell the classifier to inspect currency. This
change adds the requirement.

## Scope

`specs/price-change-detection.md` gains one ADDED Requirement
(`Suppress classification on currency flip`) and the matching
brief gets an APPEND under `Operator's local context` to
explain that `currency-flip` events are silent-by-design.

## Approach

Behavioural: prior + current snapshot's `currency` field is
compared per `(competitor_id, sku_id)`. On mismatch, the
classification request is skipped and a
`wild.{tribe}.detection.currency-flip` event fires. Real
in-currency moves continue to enqueue normally.

Risk is `high` — behavioural change, alters when an alert
fires. Operator approval required (per ADR-0018 risk-tag
conventions). The alternative — a brief-only "watch out for
currency flips" note — is `low`-risk but doesn't actually
change classifier behaviour. We need the spec edit.

## Telemetry pinning the observation (optional but expected for chief-driven changes)

- wild.pricing-monitor.detection.currency-flip — fires when prior + current currency disagree for the same SKU
- wild.pricing-monitor.classify.requested — should drop on flagged SKUs after this change merges

## Acceptance

After this change merges:

- A simulated snapshot pair where competitor B's price goes
  from EUR 89.90 to USD 89.90 (i.e. nominally identical but
  currency flipped) drops to ZERO classification requests.
- A real -50% drop where currency stays EUR continues to
  trigger classification.
- The new `currency-flip` event lets operators see how often
  this filter fires.

## Generated by

Reflect cycle on 2026-05-15: chief observed three "phantom
flash-sale" alerts on competitor B over the prior 30 days.
All three correlated with Monday morning runs and competitor
B's currency display flag flipping. Chief proposed this
