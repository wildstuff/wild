# Figures for `how-tribes-live.md`

A self-contained, **tunable** illustration workspace for
[`../../how-tribes-live.md`](../../how-tribes-live.md). Everything
here is editable source plus a rendered export — change a source,
re-render, done.

```
mermaid/    11 structural diagrams (.mmd) — the flows, loops, state machines
rendered/   their .svg + .png exports (regenerated by render.sh)
scenes/     6 hero illustrations — editable .svg mockup + .png + an AI prompt (.md)
render.sh   re-render every mermaid source → rendered/
```

## Two kinds of figure

| | Structural diagrams (`mermaid/`) | Hero scenes (`scenes/`) |
|---|---|---|
| **What** | Flows, the loop, the lifecycle state machine, the timeline. | Editorial illustrations: the flip, the medallion vats, the forge. |
| **Source you tune** | `*.mmd` (Mermaid text — easy). | `*.svg` (open in any vector editor: Figma, Illustrator, Inkscape, even Excalidraw via *Import SVG*). |
| **AI route** | — | each scene also has a `*.md` **prompt** — paste into an image model for a high-fidelity version. |
| **Re-render** | `./render.sh` | open the `.svg`, export PNG (browser → screenshot, or any SVG→PNG tool). |

The `scenes/*.svg` files are deliberately simple flat mockups — a
*starting point* that's correct in composition, palette, and
labels. Tune them directly, or use the matching `*.md` prompt to
generate a richer illustration and drop it in beside the mockup.

## Rendering

```bash
./render.sh        # render every mermaid/*.mmd → rendered/{name}.svg + .png
./render.sh 06     # only files matching "06"
```

No global install needed — `render.sh` pulls `@mermaid-js/mermaid-cli`
through `npx` (cached after the first run). Theme/​background are set
at the top of the script; change `THEME` to restyle the whole set.

The doc itself embeds the Mermaid **source** inline, so GitHub
renders those diagrams without any export step — `rendered/` is for
slide decks, PDFs, and other non-GitHub contexts.

## The shared look

Palette and the style suffix that keeps the hero set coherent live
in [`scenes/style.md`](scenes/style.md). The structural diagrams use
Mermaid's `neutral` theme for a calm, low-chrome look that sits well
next to the hand-drawn scenes.
