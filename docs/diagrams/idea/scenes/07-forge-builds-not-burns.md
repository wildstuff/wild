# Hero scene — Why forge, when there's an LLM?

## Prompt

**The forge argument.** *Two cards side by side on warm paper under the
title "Why forge, when there's an LLM?" and the kicker "recurring work is
the worst place for a model". Left card, "Read it with a model — every
time": a document labelled "the scan" feeds a chip labelled "model"; a
dashed loop arrow runs back to the document marked "again next month";
five orange tick marks count "tokens, every run"; below, three slightly
tilted reading chips disagree — "1,240.00 €", "1.240,00 €", "1240 €" —
noted "three runs, three readings"; caption "Every run pays again — and
the answers wobble." Right card, "Forge it — once": the same document
meets an anvil with orange sparks; out comes a chip "parser ✦ forged",
noted "real code — no model in the loop"; below, three identical reading
chips, each with a green check — "every run, the same reading"; caption
"Built once — same input, same answer." Beneath both cards, "What the
smithy forges": two green pills — "tools — parsers · converters ·
fetchers" and "whole workers — watchers · notifiers · indexers" — with
the fence line "sandboxed · approval-gated · content-pinned — and never
new doors to your files or the network". Footer, hand-lettered italic:
"Judgment goes to the model. Repetition goes to code."*
